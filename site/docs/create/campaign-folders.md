# Campaign folders

A folder groups campaigns so you can share all of them with a teammate in one step, instead of granting access campaign by campaign.

**Where to find it:** sidebar → **Campaigns** → **Manage folders**

**Manage folders** is for organization admins. Everyone else sees "Folders are managed by org admins."

## Create a folder and add campaigns

1. Open **Campaigns** and click **Manage folders**. The page is called "Campaign folders."
2. Type a name in **New folder** and click **Create**.
3. Select the folder in the **Folders** list.
4. Under **Campaigns in this folder**, choose a campaign in **Add a campaign** and click **Add**.

To take a campaign out of a folder, click **Remove** next to it. A new folder says "No campaigns in this folder yet."

## Share a folder

1. Select the folder and find **People**. It says "Who can access every campaign in this folder. Viewers can read them; Managers can also edit them."
2. Under **Person**, choose a teammate.
3. Under **Role**, choose **Viewer** or **Manager**.
4. Click **Grant access**.

Use **Remove** to take access away.

## Delete a folder

Click **Delete folder** and confirm "Delete this folder? This does not delete the campaigns in it."

## FAQ

**Does a folder give access to future campaigns?** It gives access to the campaigns in the folder. A campaign you add later is covered once it is in the folder.

**What happens to campaigns when I delete a folder?** They stay. Only the folder is deleted.
